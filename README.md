# TodoApp MVC

A simple desktop todo application built with Java Swing using the MVC pattern.

## Features

- Add tasks
- Toggle OPEN/DONE status
- Delete selected tasks with Delete key
- Clear all DONE tasks
- Keyboard navigation support
- Help menu with shortcuts

## Technologies

- Java
- Swing
- MVC Architecture

## Shortcuts

| Shortcut | Action |
|---|---|
| Enter in TextField | Add task |
| Enter on task list | Toggle task status |
| Double Click | Toggle task status |
| Delete | Remove selected task |
| Tab | Navigate components |
